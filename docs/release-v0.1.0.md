# ContainerPreview 0.1.0

## English

First formal release of the client-side world-container preview for Minecraft
Bedrock and LeviLauncher. Hold Left Alt to view supported container contents
with native item icons without showing the container screen.

- Exact Windows x64 Minecraft 1.26.45.01 / 1.26.51.01 / 1.26.52.03.
- Ordinary/double chests and your own Ender Chest; permitted native background
  opening in Survival, Creative and Adventure, including supported held items.
- Additional single-player read-only adapters and experimental exact Hive
  death-crate support. No server plugin or companion protocol.
- JSON enable/disable and hold-key settings with automatic reload.

The focused manual round passed on all three versions. This is not universal
server/container/mod or long-duration certification. Normal permissions and
server rules apply. Background opening can trigger ordinary events, sounds,
lid animation and loot generation. See the README and compatibility notes.

The DLL is unchanged from the accepted test31 build; a startup line of
`0.1.0-test31` is expected. Only the package metadata/docs are formalized.
Download the plugin ZIP, not GitHub's automatic source-code archives. Extract
its eight files to `mods/ContainerPreview` with Minecraft fully closed; retain
existing config/logs. Archive and per-file SHA-256 checksums are provided.

## 繁體中文

客戶端世界容器預覽的首個正式版，適用於 Minecraft 基岩版與 LeviLauncher。
按住左 Alt，不顯示容器介面即可查看支援容器的內容與原生物品圖示。

- 精確支援 Windows x64 Minecraft 1.26.45.01／1.26.51.01／1.26.52.03。
- 普通／大箱子與自己的終界箱；支援生存、創造、冒險中的正常原生背景
  開啟，包括核實的持物狀態。
- 額外單人唯讀適配與實驗性 Hive 死亡箱，不需要伺服器插件或配套協定。
- JSON 控制啟用／停用與預覽鍵，設定自動重載。

三版本均完成本輪人工驗收，不代表所有伺服器、容器、插件或長時間情境
皆已通過。仍需遵守正常權限與伺服器規則；背景開啟可能觸發正常事件、
聲音、箱蓋動畫及戰利品生成，詳見 README 與相容性說明。

保留 test31 原已驗收 DLL，啟動顯示 `0.1.0-test31` 屬正常，僅套件資訊與
文件正式化。請下載插件 ZIP，不是自動產生的 Source code。退出遊戲後將
八個檔案放入 `mods/ContainerPreview`，保留原設定與日誌；附 ZIP 及逐檔
SHA-256 校驗碼。
